# 个人记账系统

一个面向中文用户的本地单用户记账工具。数据保存在本机 SQLite 数据库中，支持支付宝、微信和历史 Excel 账单导入，提供月度分析、流水管理、公费报销跟踪与 Excel 备份。

## 特点

- 本地运行，无账号、无云端同步，账目默认保存在 `data/account_book.db`。
- 支付宝、微信账单自动解析、去重和过滤；重复导入不会重复写入。
- 支持账户、分类、消费标签、备注、交易对方、支付方式和报销状态。
- 流水列表采用本地表格组件，选择、全选和编辑草稿不会导致页面刷新。
- 收入、支出、退款、过手往来和公费垫付分别统计，退款会从个人支出中扣除。

## 功能说明

### 仪表盘

- 使用“年份下拉框 + 12 个月按钮”选择统计周期；无流水的月份不可选择。
- 展示个人收入、个人支出、结余和交易笔数。
- 单独展示当月过手转出、过手转入、待报销总额和已收回报销金额。
- 提供年度分类支出汇总表、月度收支趋势、当月分类支出饼图、收入标签占比图和支出标签占比图。
- 提供公费垫付报销清单，便于查看待报销与已结清记录。

个人收支统计会自动排除“公费垫付”“垫付报销”“过手转出”和“过手转入”。

### 流水列表

- 选择年份和月份后，一次显示该月全部流水，不分页。
- 关键词搜索备注、分类和交易对方；输入关键词时可搜索整个数据库，清空后回到当前月份。支持 `AND` / `且`、`OR` / `或`：`AND` 优先于 `OR`，例如 `水果 AND 超市`、`水果 OR 咖啡`。
- 支持账户、收支、分类、标签、最低金额和最高金额组合筛选。
- 支持勾选行、表头全选、批量删除和单条修改。
- 支持“修改流水”进入当前可见流水的整表编辑模式；只有点击保存才写入数据库。
- 编辑模式支持单击编辑、下拉选择、消费标签批量设置、复制粘贴、键盘导航和取消确认。
- 本地表格支持固定表头、横向滚动、列宽调整、列顺序拖动、复制单元格内容和日期显示切换。
- 调整后的列布局保存在当前浏览器；恢复默认布局需要二次确认。

当存在未保存的整表编辑时，页面导航、年份、月份和搜索会被锁定；账户、收支、分类、标签及金额筛选仍可使用，筛选只改变可见行，全部编辑草稿会一直保留到保存或放弃修改。

### 账户、分类、标签与报销

常用账户包括支付宝、微信、现金、银行卡、美团月付和手动录入，也可保留历史导入账户。

支出和退款共用分类：生活费用、伙食费用、交通出行、休闲娱乐、办公学习、外出旅游、医疗保健、服饰鞋帽、非日用品、其它支出、过手转出和公费垫付。收入分类包括工资收入、生活费收入、转账收入、银行利息、兼职收入、其它收入、过手转入和垫付报销。

- 支出可设置消费标签：生存刚需、品质生活、自我投资、人情往来。
- 收入可设置劳动收入、财产收入、转移收入标签。
- 侧边栏提供“选项管理”，可在应用内新增、重命名和删除账户、支出/收入分类及标签；重命名会同步既有流水，删除仅影响后续可选项并保留历史值。支出分类（含退款）和收入分类均可维护“自动关联标签”列。
- 退款可设置与支出相同的标签；统计个人支出时会从对应支出中扣除退款金额。
- 工资收入和兼职收入默认关联“劳动收入”，银行利息默认关联“财产收入”，生活费收入和其它收入默认关联“转移收入”；自动填入后仍可手动修改。
- 选项管理、报销清单、账单导入预览和自动过滤记录均使用本地表格样式，支持固定表头、横向滚动、列宽调整和列顺序拖拽；删除选项时需二次确认。
- 公费垫付默认“待报销”，可改为“已结清”；待报销淡红、已结清淡绿。
- 垫付报销默认“已结清”，不改变行底色；过手转入默认“待转出”，待转出淡红、已转出淡绿；过手转出默认“已转出”，不改变行底色。
- 收支或分类切换后，不兼容分类与状态会自动清空；上述四类分类会自动写入对应默认状态。

### 导入账单与备份

#### 支付宝与微信

- 支持支付宝 CSV/XLSX、微信 CSV/XLSX 官方账单。
- 自动识别表头、编码和常见字段名称，统一映射到账户、收支、金额、分类、备注、对方和支付方式。
- 使用 `import_hash` 去重，重复导入自动跳过。
- 导入后展示新增、重复跳过、自动过滤和预览结果。

自动过滤规则：

- 支付宝：余额宝收益发放、花呗自动还款、银行卡定时转入。
- 微信：转入零钱通；同时检查备注和映射后的分类。

被自动过滤的记录不会写入数据库，但会保存在当前浏览器会话的历史过滤记录中，可在导入页查看或清除。刷新页面、关闭浏览器或重启服务后，这些会话记录会清空。

#### 历史 Excel

解析器支持导入旧版记账 Excel 的支出与收入流水表，包括 `支出表`、`收入表`、`Sheet1`、`Sheet2` 与 `Sheet3`。支持“备注 发红包的人”备注列，并保留支出标签；日期仅含日期时自动补为当天零点。

导入页可导出数据库中的全部流水为 Excel 备份。

### 手动记账

- 填写日期、账户、收支、金额、分类、标签、备注、对方和支付方式。
- 金额按正数输入，系统按收支类型自动保存为收入和退款正值、支出负值；统计支出时退款会被扣除。
- 手动录入也使用去重规则，避免重复提交。

## 数据规则

| 项目 | 规则 |
| --- | --- |
| 金额 | 数据库中收入和退款为正、支出为负，统一保留两位小数并四舍五入；界面输入始终为正数，统计支出时退款会被扣除。 |
| 去重 | `import_hash` 是导入去重键；手工修改不会改写它。 |
| 公费垫付 | 只能是支出，状态为待报销或已结清。 |
| 垫付报销 | 只能是收入，状态为已结清。 |
| 过手转入 | 只能是收入，状态为待转出或已转出。 |
| 过手转出 | 只能是支出，状态为已转出。 |
| 数据库 | 所有账目保存在本地 `data/account_book.db`。 |

## 快速开始

### 环境要求

- Windows 10/11
- 源码运行支持 Python 3.10 或更高版本
- 打包 EXE 需要 64 位 Python 3.14

仅以源码运行时，首次使用请在项目目录安装依赖：

```powershell
python -m pip install -r requirements.txt
```

### 启动方式

日常使用推荐双击桌面的“个人记账”快捷方式。首次需要在项目目录的 PowerShell 中执行一次打包命令；完成后会自动生成该快捷方式，双击即可启动并打开浏览器。

```powershell
.\build_exe.ps1
```

桌面程序会自动选择可用端口，账本保存于程序目录下的 `data/account_book.db`。

未打包时，仍可双击 [启动.bat](启动.bat)。该脚本会关闭占用 8501 端口的旧服务，以后台方式启动应用，并自动打开浏览器。

也可使用命令行：

```powershell
python -m streamlit run app.py --server.port 8501 --server.headless true
```

或使用启动器自动分配端口：

```powershell
python launcher.py
```

默认地址为 `http://localhost:8501`。

## 打包为桌面程序

在项目目录的 PowerShell 中执行：

```powershell
.\build_exe.ps1
```

构建结果位于 `dist\CodexAccountBook\`，并会在桌面创建“个人记账”快捷方式。打包脚本会自动完成以下工作：

- 仅使用 Python 3.14，每次重新创建项目内的 `.venv-build` 独立打包环境。
- 按 `requirements-build.lock.txt` 的完整固定版本安装依赖；默认使用可访问的清华 PyPI 镜像，也可通过 `PIP_INDEX_URL` 覆盖。
- 在 `.package-staging` 中构建，检查必要模块并实际运行一次隔离的 Streamlit 会话。
- 验证通过后才停止旧程序、校验并保留原账本，再替换正式发布目录；构建失败不会提前删除现有 EXE 或数据。
- 如正式发布目录正被 Windows 占用，自动改用原位同步完成更新。

日常启动只需双击快捷方式，无需再使用 BAT 文件。窗口模式启动失败时会弹出错误提示，并在 EXE 同级生成 `startup-error.log`。

## 项目结构

| 文件或目录 | 说明 |
| --- | --- |
| `app.py` | Streamlit 页面、会话状态、筛选、表单、图表和本地表格交互。 |
| `db.py` | SQLite 建表、迁移、CRUD 与统计聚合。 |
| `parser.py` | 支付宝、微信和历史 Excel 账单解析、去重与自动过滤。 |
| `local_transaction_editor.py` | 本地表格 Streamlit 组件入口。 |
| `components/transaction_editor/` | 本地表格前端资源。 |
| `launcher.py` | 自动端口、浏览器打开与冻结模式启动器。 |
| `启动.bat` | Windows 一键后台启动脚本。 |
| `build_exe.ps1` | Python 3.14 独立环境、暂存验证、数据保护与 PyInstaller 打包脚本。 |
| `requirements-build.lock.txt` | EXE 构建使用的完整固定版本依赖清单。 |
| `verify_packaged_app.py` | 对暂存包执行隔离 Streamlit 会话验收。 |
| `data/account_book.db` | 本地 SQLite 账本数据库。 |
| `更新记录.md` | 已交付功能的按日期更新记录。 |

## 注意事项

- 导入前建议先导出 Excel 备份。
- 自动过滤记录仅为浏览器会话级复核信息，不是永久数据。
- 删除流水和恢复默认列布局属于不可逆操作，操作前请确认。
- 同一台电脑上不要同时启动多个占用同一端口的应用实例。
- 如需了解开发规范和架构约束，请阅读 `AGENTS.md`。
